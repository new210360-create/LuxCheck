# LuxCheck 本機版

網址：http://127.0.0.1:4190/

雙擊「開啟LuxCheck.cmd」會啟動本機服務並開啟瀏覽器；雙擊「停止LuxCheck.cmd」可停止服務。服務僅供本機存取，沒有設定開機自動啟動。

Three.js 0.147.0 與 OrbitControls 已存放於 vendor，正常操作不需要外部 CDN。需支援 WebGL 的瀏覽器使用 3D 檢視。

專案自動保存在此網址的瀏覽器 IndexedDB，會優先讀取新版存檔；沒有新版存檔時自動讀取舊版 localStorage。請使用「儲存」下載 JSON 作為正式備份；清除瀏覽器資料、換瀏覽器或改網址不會自動帶入原專案。

## CAD 匯入與模擬

1. 按「匯入 CAD」，選擇 DWG 或 ASCII DXF（30 MB 以下）。DWG 使用本機 AutoCAD 2025 Core Console 轉為暫存 DXF，原檔不修改、不上傳雲端。轉換上限 120 秒。
2. 核對 CAD 單位（毫米、公分、公尺、英吋、英呎），或按「點兩點校正」，輸入兩點實際距離（公尺）。建議另以第二組已知尺寸核對。
3. 選擇空間封閉輪廓，綠線為實際計算範圍；沒有封閉輪廓可按「手動圈選空間」逐點圈選後完成。請排除圖框、其他樓層。
4. 選辦公桌圖層或圖塊，藍色填色為桌面。桌面圖層或圖塊名稱包含 DESK／TABLE／桌／工作站時會預選，仍需核對。點預覽中的封閉輪廓可個別加入／排除桌面。旋轉／縮放巢狀圖塊會展開，簡單 LINE 封閉環也可識別；開放、分叉線段不會猜測成桌面。
5. 套用後，所有桌面固定 0.75 m，其他區域 0 m。桌面保留邊緣格點；牆邊排除帶只影響地面。右側列出全部桌面、地面及個別桌面的平均／最小照度與均齊度。
6. 設定天花高，選燈具與「新增／佈燈高度」後手動放燈或自動佈燈。燈具高度為發光面距地面；崁燈通常等於天花高，軌道燈可設較低高度，選取單燈後設定傾角、旋轉、光束角。可混用多種燈具，逐盞、同型號或全體批次調整。
7. 2D 顯示 CAD／桌面與照度，3D 顯示 75 cm 桌面與地面各自的照度。JSON 存檔包含 CAD 幾何、桌面辨識、尺寸校正、來源 SHA-256 與燈具；報告列出分區高度與照度。

地面照度預設目標為 100 lx、均齊度 0.4；100 lx 可在左側調整，僅為起始設計目標。桌面依選定辦公標準或自訂值檢核。綜合判定包含每個桌面及地面，無格點桌面會標示未通過，需縮小格點。

支援 LINE、LWPOLYLINE／POLYLINE（含圓弧段）、ARC、CIRCLE、ELLIPSE 與 INSERT 圖塊；曲線會取樣成線段。文字、尺寸與未支援物件不作計算幾何，匯入頁列出忽略的其他類型；HATCH、SPLINE、外部參考等請先轉為線段／多段線或併入圖面。桌面是計算面，尚未納入家具或隔間的光線遮擋。間接光與 UGR 沿用近似估算。

## 驗證

deployment/cad-ui-verification.json 記錄無頭 Edge 操作測試，包含 12 × 8 m／96 m²／3 個桌面、原生 AutoCAD DWG 轉換、0／0.75 m 格點、混用軌道燈與崁燈、燈高與傾角、JSON 重開、自動儲存重載、復原、PDF 分區報告。deployment/test-cad-geometry.cjs 檢查毫米換算、旋轉圖塊、LINE 環與分區照度數值。實際使用者 CAD 圖檔尚待驗證。

計算方法與設計參考用途沿用原版。
